说明：预览用 HTML/CSS 近似 iOS 系统控件，字体、间距、圆角与真机可能有数像素差异； 双指拖拽和三指上滑无法用鼠标模拟，只在触控区提示与右侧状态里体现。预览文件与 Swift 源码保持同步， 真正出包要 push 后由 GitHub Actions 完成。
引导页卡片宽度：SwiftUI 的 VStack 默认按最宽子视图定宽；连接日志初始只有一行短日志时 会缩成窄卡片并居中，与上方两张卡片不对齐。现在三张卡片都显式撑满父宽度（预览里对应 `.card` / `.diag` / `.logbox` 的 `width:100%`），日志内容区也铺满卡片；高度仍为 108pt。
断开 / 停止广播已删除：实测点「断开」后系统会立即自动回连、「停止广播」也不起作用， 两者没有实际意义，已从工具栏移除。未连接时只保留「开始广播」（桥接模式为「连接桥接」）入口。 要换设备须在旧设备上忽略本设备（iPad：设置 → 辅助功能 → 触控 → 辅助触控 → 设备 → 点键盘 → 忽略此设备，不在蓝牙列表里）。
三指上滑：复合模式下发送键盘报告 Command+M 让 iPadOS 最小化当前程序 / 回桌面（App 保留后台不关闭），真机需三指同时 上滑 80pt 以上。这是实验功能，iPad 可能把设备识别为键盘而拒绝接管整个设备；此时关掉设置里的 「键鼠复合模式」、忽略设备重新配对即可回退到纯鼠标，不需要重装 App。
全键盘：已连接时点触控区顶部蓝色「全键盘」按钮切换到两页虚拟键盘；键盘页顶部「‹ 触控板」 返回。主键位页含 F1~F12、数字 + QWERTY、Esc / Tab / Caps / Del / Home / End 与四向方向键； 符号页是上档符号、US 标点两行，以及 Ins / PrtSc / ScrLk / Pause / PgUp / PgDn / Menu。 原来的独立「功能」页已并入主键位，功能键一个不丢。
Esc / ↑ 位置：主键位第 5 行左右原来的空白 spacer 已换成按键， Esc 贴 Z 左侧、↑ 贴 M 右侧，分别顶到键区左右边缘；第 6 行不再重复放这两个键。
小触控区：键区紧贴顶部工具条，其下剩余空间全部是触控区（紧贴键区、无标题与提示文字）， 复用全屏触控板的全部手势（单指移动 / 点击 / 双指拖拽 / 三指上滑），打字时也能移指针。 底部常驻 Ctrl / Opt / Cmd / Shift 一次性粘滞修饰键，组合键先点修饰键再点字符键。底部左键 / 滚轮 / 右键在键盘模式下依旧可用。
本轮精简：底部三键高度从 116pt 降到 76pt，把空间让给触控区；键盘页上方的粘滞长句说明、 小触控区标题、触控区内三行提示、底部「Esc / ↑」说明文字全部删除。按键标签、分段控件、返回按钮和 条件性的橙色「键盘暂不可用」警告保留（后者是错误提示，不是说明文案）。
再往上挪一点点：工具条下方那条 24pt 的空状态条整行删掉，粘滞状态改为工具条右侧 「⌃ ⇧ ⌥ ⌘ 清除」短徽标（只在生效时出现，点一下清除）；键区顶部间距 8pt → 2pt、 小触控区顶部间距 6pt → 4pt。省下约 30pt 全部给小触控区，键区上移且不产生垂直跳动。
键盘限制：按键走 USB HID 键码（0x00~0x65），中文、emoji 和输入法切换由主机决定，不能直接写入字符； 多媒体键（音量、亮度）属于 Consumer Page，本描述符未声明，无法发送。全键盘与三指上滑共用 12 字节键鼠复合报告， 必须保持「键鼠复合模式」开启并在 iPad 忽略设备后重新配对。
三指切 App：三指左右滑 = Cmd+Tab / Cmd+Shift+Tab 切换 App（App 侧识别手势转成键盘快捷键的模拟实现，不是系统原生手势）。依赖「键鼠复合模式」开启，共用 12 字节复合报告，在 iPad 忽略设备后重新配对即可生效。
触控板模式（已撤销）：曾经尝试把 GAP Appearance 从 Mouse 改成标准 Touchpad(0x03C9) 让 iPad 出现「触控板」菜单，实测无效——iOS 不允许第三方 App 注册系统强制管理的 GAP 服务(0x1800)，App 写的外观值主机根本读不到；且 iPad「触控板」菜单与原生手势只对妙控板私有协议开放。此开关已移除，三指切 App 改为直接挂在键鼠复合模式上。
